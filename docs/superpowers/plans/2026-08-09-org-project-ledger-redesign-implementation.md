# 组织项目总账页面优化实施计划

日期：2026-08-09

设计依据：`docs/superpowers/specs/2026-08-09-org-project-ledger-redesign.md`

## 成功标准

- 项目总账展示项目信息、阶段、负责人、跟进人、进度、风险、目标日期和更新时间。
- 搜索、筛选、“只看我的”、归档和分页均通过 URL 状态工作。
- 阻塞、延期和关注项目按确认规则优先排序。
- 风险摘要基于组织内全部活跃项目计算。
- 项目详情采用概览主栏与责任侧栏，编辑表单不再与展示内容重复堆叠。
- 亮色、暗色、桌面和窄屏均可用，无不可控的页面级横向溢出。

## 任务 1：锁定设计系统与现有行为

- 写入 `design.md`、`tokens.css` 和 Hallmark 项目记录。
- 运行现有 orgproject Go 与 Vue 定向测试作为基线。
- 验证现有默认字段和权限边界。

## 任务 2：查询与总账数据

- 为列表查询添加参数化名称搜索和“只看我的”。
- 从发布配置解析阶段、风险、负责人、跟进人和目标日期筛选。
- 添加风险优先排序，保留稳定 ID 次排序。
- 添加组织级风险摘要查询。
- 补充编译器、列表和摘要单元测试。

## 任务 3：服务端展示模型

- 将动态字段转换为带类型、原始值和成员信息的展示模型。
- 批量加载组织成员，避免逐行成员查询。
- 为总账提供筛选配置、当前条件和风险摘要。
- 保留查询参数到分页链接。

## 任务 4：项目总账界面

- 重构 dashboard/list 模板为统一的项目总账壳。
- 实现风险摘要、搜索筛选工具栏、无结果状态和清除条件。
- 重构 `ProjectDashboard.vue` 与 `ProjectList.vue`，增加字段类型化展示。
- 补充 Vue 组件测试。

## 任务 5：项目详情界面

- 重构详情头部、页签、概览主栏、责任侧栏和关联仓库区。
- 使用 URL 查询参数控制查看/编辑状态，不引入新的路由树。
- 复用现有 `ProjectForm.vue`，按核心字段分组并保持动态字段兼容。
- 将代码活动和变更记录接入统一页签视觉。

## 任务 6：样式与响应式

- 在 `org-project.css` 中使用项目令牌，覆盖总账、状态标签、进度、头像组和详情布局。
- 保留 Gitea 主题变量与控件样式。
- 检查 320、375、414、768px 和桌面宽度。
- 确保焦点、空状态、表格滚动和 reduced-motion 正常。

## 任务 7：验证

- `make fmt`
- `make lint-go`
- `make lint-js`
- 运行受影响的 Go 单测。
- 运行 orgproject Vue 单测。
- 使用应用浏览器检查总账、筛选、详情编辑、暗色和窄屏。
- 截图并与已确认的浏览器视觉概念逐项比较。
