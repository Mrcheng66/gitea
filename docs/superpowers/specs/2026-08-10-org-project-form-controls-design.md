# 组织项目表单控件统一设计

## 概述

统一“组织项目”模块内的下拉选择器与日期输入控件，解决当前原生选择器宽度不一致、空值控件过窄、多选展示生硬，以及日期字段与其他输入框视觉脱节的问题。

已确认采用视觉方案 **B：清晰平衡**，技术方案采用项目现有的 Fomantic 下拉组件增强原生 `<select>`，日期和日期时间字段保留浏览器原生选择能力。所有新增样式和行为限定在组织项目模块，不影响 Gitea 其他页面。

## 目标

- 统一组织项目新建、编辑、配置和列表筛选中的下拉控件。
- 统一组织项目日期与日期时间输入框的尺寸、边框、圆角、图标和状态反馈。
- 固定枚举保持简洁，成员选择支持搜索，多选值使用紧凑标签展示。
- 保留现有 Vue 状态、字段序列化、原生表单提交和后端接口。
- 保持浅色与深色主题、键盘操作、无障碍语义和窄屏布局可用。
- JavaScript 增强失效时保留可提交的原生控件。

## 非目标

- 不修改组织项目以外的 Gitea 页面。
- 不替换浏览器原生日期或日期时间弹层。
- 不引入新的下拉框、日期选择器或弹层依赖。
- 不修改字段配置结构、路由、后端验证、数据库或提交协议。
- 不改变组织项目的字段分组、页面结构和业务规则。
- 不为成员选择增加远程分页或服务端搜索；本次搜索基于页面已加载的组织成员。

## 设计方向

### 视觉语言

控件采用已确认的“清晰平衡”方向：

- 高度统一为现有 Gitea 标准表单高度，目标视觉高度为 38px。
- 圆角统一为 8px，并通过组织项目设计令牌或 Gitea 主题变量表达。
- 默认状态使用清晰的中性边框和表单背景。
- 悬停时加深边框；聚焦或展开时使用项目主色边框和柔和焦点环。
- 下拉菜单与触发控件等宽，使用轻量阴影和有限高度滚动。
- 空值显示统一占位文本，不出现无文字的窄小选择框。
- 所有颜色从现有主题变量派生，浅色和深色主题不使用独立硬编码配色。

### 控件映射

| 字段或场景 | 控件行为 |
| --- | --- |
| `single_select`、阶段、风险、聚合方式、排序方向、筛选运算符等固定枚举 | 普通 Fomantic 单选下拉 |
| `member`、负责人、字段值为单个成员 | 可搜索的 Fomantic 单选下拉 |
| `multi_select` | Fomantic 多选下拉，已选项显示为标签 |
| `member_array`、跟进人 | 可搜索的 Fomantic 多选下拉，已选成员显示为标签 |
| `date` | 原生 `input[type="date"]`，应用统一外观 |
| `date_time` | 原生 `input[type="datetime-local"]`，应用统一外观 |
| 组织项目列表筛选 | 与表单固定枚举一致的紧凑单选下拉 |

## 作用范围

### 项目表单

`ProjectFormField.vue` 是可配置项目字段的主要渲染边界。它负责为不同字段类型选择相应的下拉增强类或日期控件类，覆盖新建页和详情编辑表单。

长文本、数字、百分比、布尔值和普通文本字段保持现有行为。多选字段继续占据完整表单行。

### 配置控制台

以下配置编辑器中的原生选择器应用同一套固定枚举下拉外观：

- `FieldEditor.vue`
- `MetricEditor.vue`
- `ViewEditor.vue`

配置编辑器仍由现有 `v-model` 持有值。字段列表或可选项变化后，下拉菜单应反映最新的底层 `<select>` 选项。

### 服务端模板

组织项目服务端模板中的筛选和关联表单选择器应用相同的模块级类，包括：

- `templates/orgproject/shared/ledger.tmpl` 的字段和到期筛选器。
- `templates/orgproject/view.tmpl` 的仓库角色选择器。

模板继续提交原有字段名和值，不增加新的隐藏业务字段。

## 组件与初始化边界

底层 `<select>` 始终是真实数据源和表单控件。Fomantic 只负责将其增强为一致的选择界面：

- 固定选项使用 `selection dropdown`。
- 成员选择增加 `search` 能力。
- 数组选择增加 `multiple` 行为和标签展示。
- 原生 `required`、`disabled`、选项值和 `multiple` 属性保持不变。

Vue 和服务端模板渲染的选择器统一添加项目现有的 Fomantic 类，并由全局 selector observer 初始化。该入口已经覆盖后续插入 DOM 的 Vue 节点，并会跳过已有实例，因此组织项目不增加第二套初始化器。

Fomantic 自带的 select observer 负责在 Vue 更新 `<option>` 后重建菜单内容。组织项目组件不持有额外的下拉状态或全局事件处理器；组件或页面移除时，增强后的 DOM 与底层控件一同移除。

## 数据流

1. 服务端渲染项目字段配置、初始值、成员列表和模板筛选值。
2. Vue 创建原生 `<select>` 或日期输入，并通过 `v-model` 设置当前值。
3. Fomantic 基于底层 `<select>` 构建展示层。
4. 用户选择、搜索或移除选项时，Fomantic 更新原生 `<select>` 并触发标准 `change` 事件。
5. Vue 从同一原生事件更新 `v-model`；创建页检查清单通过现有表单事件监听同步显示值。
6. `ProjectForm.vue` 按现有协议把可配置字段序列化到隐藏的 `values` JSON 输入框。
7. 浏览器向现有路由提交相同字段，后端无需修改。

下拉展示层不拥有独立业务状态，避免 Fomantic、Vue 和隐藏 JSON 之间出现三套值。

## 交互细节

### 固定枚举

- 单击控件或使用键盘打开菜单。
- 当前项、悬停项和键盘定位项具有不同的可见状态。
- 非必填字段保留可清空的空选项，并显示统一占位。
- 菜单项目使用紧凑行高，但点击区域不低于现有 Gitea 下拉菜单标准。

### 成员选择

- 单成员字段在下拉内提供输入过滤。
- 成员数组支持搜索和多选。
- 已选成员使用浅色语义标签展示，并提供明确的移除按钮。
- 搜索仅过滤页面已加载成员，不产生网络请求。
- 无匹配结果时使用 Fomantic 现有空结果反馈。

### 多选固定项

- 已选项使用与成员多选一致的标签结构。
- 标签在控件内换行，不将页面撑出视口。
- 控件高度可随标签行数增长，单行时保持标准最小高度。

### 日期与日期时间

- 输入框与下拉控件使用相同边框、圆角、背景和焦点反馈。
- 浏览器日历或日期时间图标位于固定尾部区域，不与文本重叠。
- 日期值继续使用浏览器要求的 ISO 表单格式。
- 弹出的系统日期选择面板不做替换或模拟。
- 浏览器不支持相关输入类型时，控件退化为可输入文本并继续由服务端校验。

## 状态与错误处理

- `required` 继续使用浏览器原生校验。
- 字段错误沿用 Gitea 表单错误语义色，并确保增强后的控件边框也反映错误状态。
- `disabled` 和只读状态使用弱化背景、文字和鼠标反馈，不允许打开菜单。
- Fomantic 初始化失败时保留底层原生 `<select>` 可见和可提交。
- 配置字段没有选项或成员列表为空时，控件保持可见并展示空结果，不抛出运行时错误。
- 服务端验证失败重绘页面后，原有旧值继续恢复到原生控件，增强层从该值初始化。

## 无障碍

- 保留可见 `<label>` 与底层控件的关联。
- 继续使用项目对 Fomantic dropdown 的 ARIA 补丁。
- 搜索下拉支持 Tab、方向键、Enter 和 Escape。
- 多选标签的删除按钮具有可读名称，不能只依赖图标表达。
- 焦点状态同时包含边框和焦点环，不只依赖颜色深浅。
- 错误、禁用和已选状态不能只通过颜色传达。
- 日期字段保持浏览器和辅助技术提供的原生语义。

## 响应式设计

- 组织项目表单网格在现有断点下折叠为单列。
- 下拉控件和日期输入默认占满其字段容器。
- 下拉菜单最大宽度不超过视口，并允许长成员名省略或换行。
- 多选标签在控件内部换行，不产生页面级横向滚动。
- 列表筛选器在窄屏下占满可用宽度，继续遵循现有工具栏换行顺序。

## 测试策略

### Vue 单元测试

扩展组织项目组件测试，验证：

- 每种字段类型映射到正确的选择器、搜索、多选或日期类。
- 单选和多选更新后，隐藏 `values` JSON 保持正确。
- 成员值继续使用现有数值或数组类型，不被展示层转换为错误的字符串形态。
- 日期和日期时间值的初始化、更新与序列化保持不变。
- 配置编辑器的固定枚举选择器使用统一类名，并在选项变化后保持正确值。

### 功能测试

扩展 `web_src/js/features/org-project.test.ts` 或增加聚焦的控件测试，验证：

- Fomantic 选择触发的标准事件能更新创建页检查清单。
- 清空、重新选择和多选移除后显示值正确。
- 页面缺少可增强控件时初始化安全返回。
- 重复初始化不会创建多个实例。

### 端到端与视觉检查

扩展组织项目 Playwright 测试，覆盖：

- 新建或编辑项目时选择固定枚举成员。
- 搜索并选择负责人。
- 搜索、添加和移除跟进人。
- 选择日期后成功提交且值保持正确。
- 列表筛选器继续产生原有查询参数。
- 浅色和深色主题下的默认、焦点、展开、禁用及错误状态。
- 窄屏下没有横向滚动。

### 必须执行的检查

- 运行相关 Vitest 文件。
- 运行 `make lint-js`。
- 运行 `make lint-css`。
- 运行 `make lint-templates`。
- 本地端到端环境可用时，运行 `GITEA_TEST_E2E_FLAGS='tests/e2e/org-project.test.ts' make test-e2e`。
