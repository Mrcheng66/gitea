# 组织导航项目入口优先设计

日期：2026-08-09

## 目标

将组织页面主导航中的“项目”入口放在第一位，突出研发项目管理的核心入口。

## 变更范围

- 组织导航顺序调整为“项目 → 仓库列表 → 看板”。
- 其他现有导航项保持原有相对顺序。
- 所有组织页面使用同一顺序，避免跨页面导航跳动。

## 保持不变

- 不修改项目、仓库或看板路由。
- 不修改组织首页的默认落地页。
- 不修改权限判断、图标、文案或激活状态。
- 不调整全局顶部导航。

## 实现

仅在 `templates/org/menu.tmpl` 中移动现有“项目”导航项，将其放到仓库列表与看板之前，不新增组件或业务逻辑。

## 验证

- 运行模板静态检查。
- 检查项目、仓库和看板页面的导航顺序与激活状态。
- 确认窄屏溢出菜单仍保留相同顺序。
