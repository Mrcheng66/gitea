# 组织项目总账页面优化设计

日期：2026-08-09

状态：已确认

范围：Gitea 原生组织项目模块

## 1. 目标

为研发部门内部的代码与项目管理场景优化组织项目页面，同时服务两类用户：

- 项目负责人日常查找、跟进和维护项目。
- 管理层快速查看整体进度、责任归属和风险。

设计采用“风险优先的项目总账”。页面以便于查看和管理为第一目标，保持 Gitea 内部研发工具的克制、清爽气质，不引入独立应用壳或装饰性视觉。

## 2. 已确认的产品原则

- 项目总账是默认主视图，以可筛选表格呈现全部项目。
- 阻塞、延期、关注项目优先于正常项目。
- 总账只用于查看和进入项目，不支持列表内直接编辑。
- 项目资料在详情页统一维护。
- 保留 Gitea 组织上下文、权限和现有动态字段配置能力。
- 保留项目关联仓库、代码活动和变更记录能力。
- 本次不建设看板、流程编排、批量编辑或新的通知系统。

## 3. 视觉方向

采用克制清爽的浅色工具界面：

- 沿用 Gitea 的字体、基础颜色、按钮和组织导航。
- 使用低饱和背景、清晰边界和少量轻阴影区分层级。
- 蓝色只用于主操作、选中状态和进度。
- 红色用于阻塞和延期，琥珀色用于关注和临近目标日期，绿色用于正常或已完成。
- 风险不能只依赖颜色，同时显示文字标签或状态点。
- 信息密度适中，避免大面积装饰、渐变和纯展示型卡片。

## 4. 信息架构

组织项目空间保留以下入口：

- 项目总账：默认入口，展示风险摘要、筛选和项目表格。
- 新建项目：保留现有权限控制。
- 项目设置：仅组织配置管理员可见。

项目详情包含三个页签：

- 项目概览：项目资料、责任人、进度、日期、仓库和代码活动摘要。
- 代码活动：复用现有提交、合并请求和 Release 汇总能力。
- 变更记录：复用现有项目变更历史。

## 5. 项目总账

### 5.1 页面头部

页面标题为“项目总账”，说明为“集中查看项目责任、研发阶段、进展与风险状态”。有项目编辑权限时，右侧显示“新建项目”主按钮。

### 5.2 风险摘要

表格上方展示四个组织级指标：

- 阻塞项目数。
- 已延期项目数。
- 本周到期项目数。
- 活跃项目平均进度。

指标必须基于组织内全部活跃项目计算，不能只统计当前分页。点击前三个指标会设置对应筛选；点击平均进度不改变筛选。

### 5.3 搜索与筛选

工具栏提供：

- 搜索项目名称、负责人或跟进人。
- 按阶段筛选。
- 按风险筛选。
- 按目标日期筛选。
- “只看我的”快捷筛选，匹配当前用户负责或跟进的项目。
- 查看归档项目的入口。

筛选通过 URL 查询参数提交。翻页、刷新和浏览器前进后退必须保留筛选状态。存在筛选时提供一键清除。

### 5.4 项目表格

默认列按以下顺序呈现：

1. 项目信息：项目名称和一行说明。
2. 阶段。
3. 负责人。
4. 跟进人。
5. 进展情况：进度条和百分比。
6. 风险。
7. 目标日期。
8. 最近更新。

点击项目名称或整行的主链接进入项目详情。动态配置中缺失的值统一显示“—”。归档项目使用低强调样式并显示“已归档”标签。

默认排序规则：

1. 阻塞项目。
2. 已延期项目。
3. 关注项目。
4. 正常项目。
5. 同一优先级内按目标日期升序。
6. 无目标日期时按最近更新时间降序。

## 6. 项目详情

### 6.1 概览状态

页面头部展示项目名称、稳定标识和最近更新时间。可编辑用户看到“编辑项目”按钮。

主内容分为两栏：

- 左栏：项目说明、阶段、风险、开始日期、当前摘要、进展情况、关联仓库和近 30 天代码活动。
- 右栏：负责人、跟进人、目标日期、延期状态和最近更新时间。

阻塞或延期时，右栏显示明确提醒和下一步建议。关联仓库显示主仓库与关联仓库角色，并链接到 Gitea 原生仓库页面。

### 6.2 编辑状态

点击“编辑项目”后在当前详情页进入编辑状态，表单按以下分组：

- 基本信息：名称、标识和说明。
- 责任归属：负责人和跟进人。
- 进度与风险：阶段、进度、风险和当前摘要。
- 关键日期：开始日期和目标日期。
- 组织配置定义的其他动态字段。

保存成功后回到概览状态并显示成功提示。校验失败时保留全部输入，在对应字段旁显示错误。归档操作放在页面底部独立危险区域，不与普通保存操作并列。

## 7. 数据与交互

服务端继续负责权限、项目查询、动态字段格式化和初始页面数据。Vue 组件负责表格展示、视觉状态、编辑表单和必要的渐进增强，不复制服务端权限规则。

列表请求包含搜索、筛选、排序、归档状态和分页参数。服务端返回准确的总数、组织级指标和当前页项目。分页链接保留全部查询参数。

列表不做乐观编辑。详情保存继续使用项目版本号进行并发保护。当版本不一致时，页面提示“项目已被其他成员更新，请刷新后重试”，不得静默覆盖。

## 8. 页面状态与错误处理

- 没有项目：展示说明和“新建项目”按钮；无编辑权限时只展示说明。
- 筛选无结果：保留工具栏和当前条件，展示“一键清除筛选”。
- 配置未发布：继续使用现有配置缺失提示和设置入口。
- 指标查询失败：页面使用标准错误处理，不显示可能不准确的部分指标。
- 字段值缺失：显示“—”。
- 成员已离开组织：显示保存的名称或稳定占位，不破坏行布局。
- 表单校验失败：错误定位到具体字段并保留输入。
- 并发冲突：要求刷新后重试。

## 9. 响应式与无障碍

- 桌面端显示完整总账。
- 窄屏优先保证项目信息、风险、进度和负责人可见；完整表格可横向滚动。
- 触控目标不小于现有 Gitea 控件标准。
- 搜索和筛选具有可访问标签。
- 风险、阶段和进度都有文字表达，不依赖颜色。
- 键盘焦点使用清晰的 `:focus-visible` 样式。
- 动画仅用于轻量状态过渡，并尊重 `prefers-reduced-motion`。

## 10. 组件边界

- `ProjectDashboard.vue`：组织级风险摘要。
- `ProjectList.vue`：总账表格、字段视觉格式和空结果状态。
- 新的列表工具栏组件：搜索、筛选、只看我的和清除条件。
- 项目详情模板：概览布局、页签和编辑状态容器。
- `ProjectForm.vue`：继续负责动态字段表单，增加与详情分组一致的布局。
- `ProjectActivity.vue` 与 `ProjectHistory.vue`：复用现有数据能力并接入详情页签视觉。
- `org-project.css`：项目模块设计令牌、布局、状态和响应式规则。

组件只消费明确的属性和服务端数据，不从 DOM 文本反向推断业务状态。

## 11. 验证

- 为风险优先排序、搜索、筛选、“只看我的”和分页参数保留补充 Go 单元测试。
- 为指标计算补充全组织范围测试，覆盖归档项目、缺失日期和缺失进度。
- 为项目表格的阶段、成员、进度、风险和空值展示补充 Vue 测试。
- 为详情页编辑状态、校验失败和版本冲突补充相应测试。
- 在浏览器中检查桌面和窄屏布局、横向滚动、焦点状态、空状态和错误状态。
- 执行 `make fmt`、`make lint-go`、`make lint-js` 以及受影响模块的定向测试。

## 12. 不在本次范围

- 列表内直接编辑。
- 拖拽看板。
- 批量修改项目。
- 自定义图表或新的指标配置模型。
- 通知、订阅和自动催办。
- 新的角色或权限模型。
- 重构 Gitea 全局导航或其他非项目页面。
