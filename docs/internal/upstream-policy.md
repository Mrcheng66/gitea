# 上游维护策略

## 基线

- 上游仓库：`https://github.com/go-gitea/gitea.git`
- 固定版本：Gitea `v1.27.1`
- 固定提交：`a62dfffbe7d3a454c2f2d3c4b2788ba432724a5f`
- 定制分支：`codex/gitea-native-v1.27.1`

该分支长期停留在 v1.27.1 功能基线，不直接合并后续 Gitea 功能版本。

## 允许回移的补丁

仅回移以下两类补丁：

1. 对当前部署有影响的高危安全修复。
2. 维持受支持运行环境所必需的兼容性修复。

每个回移提交必须记录：上游来源提交、影响与风险、冲突处理、验证命令以及回滚方式。回移使用独立提交，不与本地业务功能混合。

## 数据库迁移编号

本地组织项目模块从 migration 343 开始。回移上游补丁前必须检查其迁移编号；如发生冲突，应在合入前显式重编号本地迁移，并同步修改迁移测试和本文记录。禁止依赖提交顺序隐式解决编号冲突。

## 验证与回滚

回移补丁至少执行相关单元测试、SQLite 集成与迁移测试、前后端构建和 Git 协议冒烟测试。出现回归时以普通 revert 提交回滚，禁止改写已共享历史。
